# Wajeeh Murad AlSultan — Portfolio

Personal bilingual portfolio built with Next.js, TypeScript, Tailwind CSS and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Main features
- English / Arabic toggle with RTL support
- Animated data-network hero background
- Animated role rotator and technical visual
- Responsive layout
- CV download buttons
- About, expertise, experience, selected work, technology, education and contact sections
- Reduced-motion accessibility support

## Files to edit
- `app/page.tsx`: content, sections, links and data
- `app/globals.css`: visual identity and responsive design
- `public/wajeeh-profile.png`: profile image
- `public/*CV*.pdf`: downloadable CVs
